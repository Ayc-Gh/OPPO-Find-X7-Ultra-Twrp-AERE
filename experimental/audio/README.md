# PHY110 音频原型（不在发布镜像中自动启用）

已验证原机 PAL/AGM HAL、只读原厂分区及匹配 VNDK34 的临时音频通路。用户听到低音量提示音，并确认浏览器视频有声音、播放正常。依赖原机 stock vendor、system、system_ext、ODM、vendor_dlkm、DSP 及固件；此目录不分发这些原厂分区镜像。

这是开发参考源代码，不能直接作为重启可用的安装方案。路径仍指向当次调试的 `/tmp/phy110-*` 只读挂载点；启动脚本、init 服务生命周期和 SELinux 权限尚未完成固化。将源码中的临时路径改成其他名字也不足以完成适配。

主音频 HAL 在独立可信进程运行；浏览器仍以隔离 UID 发送固定格式 PCM，不能访问 ALSA 或原厂服务。原型处理 48 kHz / 双声道 / 16-bit PCM，并校验本地 socket 凭据。修改后的播放子进程完成 PAL stop/close/deinit 后直接退出，保留 HIDL 客户端代码直到进程退出，避免卸载代码与回调线程发生竞争；三次短时静音退出测试没有新增崩溃。

准备原机 TFA 配置必须发生在扬声器驱动首次加载之前。严禁热解绑或卸载已加载的 TFA 驱动。ADSP 必须按名称识别，remoteproc 编号在不同启动间会改变；运行中的音频不应重启 DSP。

保留上游 Apache-2.0 版权标记。原型引用 AERA Waffle 音频桥设计，参见 NOTICE.md 的来源；PHY110 使用 PAL 客户端而不是 Waffle 直接 AGM 写入。
